# 대시보드 가이드

대시보드를 켜는 법은 [README](../README.md) 에 있습니다.

```bash
python dashboard/server.py --port 8899 --open
```

탭은 둘입니다.

- **AI 편집**: Codex에 편집을 맡길 요청을 만들고 지시하는 곳
- **사용자 편집**: 직접 고치고 마지막에 굽는 곳

프로젝트는 오른쪽 위 메뉴에서 만들고 엽니다. 고치면 20초 뒤 저절로 저장되고, `Ctrl+S` 로 바로 저장할 수도 있습니다.

---

## 1. AI 편집 탭

| 칸 | 내용 |
|---|---|
| 왼쪽 | 스타일 적용 / 스타일 분석 |
| 가운데 | 지시 · 메모 목록 (세로 영상일 때. 가로 영상이면 영상 아래로 내려갑니다) |
| 오른쪽 | 영상 |

### 스타일 적용 (1차 편집)

1. **편집 대상**에 원본 영상이나 폴더를 놓습니다. 같은 파일을 다시 놓으면 겹쳐 쌓이지 않고 바뀝니다.
2. **소스 파일**에는 넣고 싶은 그림 · 사진 · 효과음 · 예시 캡처를 놓습니다 (선택)
3. **스타일**과 **화면 비율**을 고릅니다.

   | 비율 | 쓰임 |
   |---|---|
   | 기본 | 스타일 (프리셋) 에 정해진 비율 그대로 |
   | 9:16 | 세로 (쇼츠 · 릴스 · 틱톡) |
   | 16:9 | 가로 (유튜브 본편) |
   | 1:1 | 정사각형 |
   | 4:5 | 조금 세로 (인스타그램 피드) |

4. 대상 영상이 둘 이상이면 **따로** (영상마다 한 편) 와 **하나로** (차례대로 이어 한 편) 가운데 고릅니다.
5. **스타일 적용**을 누르면 영상을 서버에 저장하고 **Codex에 맡기기** 창을 엽니다. **요청 복사**를 누른 뒤 같은 저장소를 연 Codex 채팅에 붙여넣으세요. 다른 환경의 채팅이면 영상도 전달해야 합니다. [Codex 편집 가이드](codex-editing.md)에 자세한 순서가 있습니다.

### 영상 위 쪽지

영상 위에 고칠 곳을 그려 둘 수 있습니다. 1차 편집 전에는 편집 대상의 첫 영상이 영상 칸에 나오므로, 원본 위에 바로 그리면 됩니다.

| 도구 | 쓰는 법 |
|---|---|
| 메모 | 누른 자리에 번호 쪽지를 붙입니다 |
| 영역 메모 | 끌어서 네모를 잡고 쪽지를 붙입니다 |
| 선 · 화살표 | 끌어서 긋습니다 |
| 곡선 화살표 | 끈 자취를 그대로 따라 그립니다 |
| 모두 지우기 | 이 영상의 쪽지를 전부 지웁니다 |

- 그리면 바로 글 칸이 뜹니다. **취소** · X · Esc 로 닫으면 방금 그린 것도 지워집니다.
- 이미 있는 쪽지의 글은 메모 목록이나 영상 위 쪽지를 두 번 눌러 고칩니다.
- 메모 목록에서 줄을 누르면 그 시각으로 갑니다. × 로 지웁니다.
- 작업 글에는 쪽지마다 시각과 화면 속 자리 (가로 · 세로 %) 가 같이 실립니다. 1차 편집 전에 그린 쪽지의 시각은 원본 시각입니다.
- 1차 편집 전 영상은 브라우저에 놓은 파일이라, 페이지를 새로 고치면 영상을 다시 놓아야 합니다. 쪽지는 남습니다.

### 지시 · 재편집

- **지시** 칸에는 영상 전체에 대한 말을 적습니다 (예: 컷을 더 촘촘하게, 말끝이 잘린다, 여백이 길다).
- 1차 편집에는 **스타일 적용**이, 그 뒤로는 **재편집** 단추가 지시와 쪽지를 함께 넘깁니다. 재편집 단추는 1차 편집이 끝난 뒤에 나타납니다.
- **자막 언어**는 쉼표로 나눠 적습니다 (`ko, en, ja`). 영상과 소리는 같고 자막만 언어 수만큼 만들어집니다.
- 대시보드는 모델 API를 직접 부르지 않습니다. 작업 글을 만들고, 사용자가 요청을 전달하면 Codex가 실행합니다. 재편집에서도 표시된 요청을 Codex 채팅에 전달하세요.

### AI 가 지키는 것

- 1차 편집에서도 **완성본을 굽지 않고** 미리보기만 만듭니다. 완성본은 사용자 편집 > 렌더에서 마지막에 한 번 굽습니다.
- 화면 잡기 · 확대 · 위치는 원본을 바꾸지 않는 값으로만 둡니다. 그래서 AI 가 1.6배로 잡은 화면도 사용자 편집 탭의 **변형**에서 1.5배로 바꿀 수 있습니다. 원본에서 다시 잘라 내므로 화질은 그대로입니다.

## 2. 사용자 편집 탭

| 칸 | 자리 |
|---|---|
| 소스 / 이펙트 | 왼쪽 |
| 뷰어 | 가운데 |
| 인스펙터 / 전사 자막 / 렌더 | 오른쪽 |
| 타임라인 | 아래 |

- 칸 사이 손잡이를 끌어 크기를 바꾸고, 두 번 누르면 기본 크기로 돌아갑니다.
- 뷰어 위 **렌더 전** 표시는 고친 것이 아직 완성본에 구워지지 않았다는 뜻입니다. 이때 미리보기는 원본 사본을 지금 컷대로 이어서 틉니다.
- 타임라인에 **컷 정보 없음**이 뜨면 아주 옛날에 내보낸 프로젝트입니다. AI 편집으로 한 번 다시 내보내면 열립니다.

### 트랙

| 트랙 | 자리 | 들어가는 것 |
|---|---|---|
| V1 · A1 | 가운데 선 바로 위 · 아래 | 이 편의 원본 |
| V2.. | V1 위로 | 덧 영상 · 그림 · **자막** |
| A2.. | A1 아래로 | 덧 소리 |

- 쓰는 트랙까지만 보입니다. 원본만 있으면 V1 과 A1 만 나옵니다.
- 클립을 끄는 동안에는 맨 위 (오디오는 맨 아래) 에 빈 트랙이 하나 더 생깁니다. 거기에 놓으면 트랙이 늘어납니다.
- 끌다가 칸 끝에 닿으면 저절로 넘어갑니다.
- 놓일 자리는 주황 점선으로 미리 보입니다.
- 자막도 비디오 트랙에 놓입니다. 트랙을 정하지 않은 자막은 V2 부터 비어 있는 트랙에 들어가고, 겹치면 한 칸 위로 올라갑니다.

### 클립을 다른 트랙으로

- **원본 클립을 V2 위로 끌기** (또는 우클릭 → 위 트랙으로): 같은 원본 구간 · 같은 화면 (AI 가 잡은 화면 · 변형 · 색 · 그룹) 을 가진 덧 영상이 됩니다. 그 구간의 자막도 그대로 남습니다.
- **A1 소리를 A2 아래로 끌기**: 소리만 아래 트랙으로 갑니다. A1 자리는 빗금으로 표시되고, 그 구간의 원본 소리는 꺼집니다.
- **연결 (고리) 아이콘**에 따라 움직이는 것이 달라집니다.
  - 켬: 영상과 소리가 같이 움직이고, V1 · A1 에는 빈 자리가 남습니다.
  - 끔: 끈 쪽만 움직이고, 남은 쪽은 빗금으로 표시됩니다.
- **원본에서 온 덧 영상 · 소리를 V1 · A1 에 놓으면** 다시 원본 클립이 됩니다. 빗금 자리가 있으면 그 자리를 되살리고, 두 프레임 안쪽으로 겹치면 옆 클립에 붙여 놓습니다.

### 리플

툴바의 **리플**을 켜면, 클립을 자르거나 지우거나 끼워 넣을 때 그 뒤가 같이 당겨지고 밀립니다.

- 위 · 아래 트랙의 덧 클립과 **자막** 단추로 넣은 자막도 함께 움직입니다.
- 고친 자리 말고 다른 빈 자리 (클립을 위 트랙으로 올리며 생긴 자리 등) 는 그대로 남습니다.
- 리플을 끄면 뒤가 움직이지 않습니다. 줄인 자리는 빈 틈이 되고, 옮길 때는 빈 자리에만 놓입니다.

### 마우스

| 동작 | 결과 |
|---|---|
| 클립 누르기 | 고르기 (재생 위치는 그대로) |
| 클립 끝 끌기 | 길이 바꾸기 (리플을 따름) |
| 클립 가운데 끌기 | 옮기기. 리플 켬이면 끼워 넣고, 끔이면 빈 자리에만 놓음 |
| 빈 곳 끌기 | 상자로 여럿 고르기 (Shift 를 누르면 더하기) |
| 눈금 · 재생 선 끌기 | 재생 위치 옮기기 |
| 우클릭 | 그룹 만들기 · 풀기 · 이름 바꾸기, 트랙 옮기기, 자르기, 지우기 |
| 전환 표 누르기 | 전환만 고르기 |
| 전환 표 양 끝 끌기 | 전환 길이 바꾸기 (앞뒤가 같이 늘고 줄어듦, 0.1–3초) |
| 자막 끌기 | 다른 비디오 트랙으로 옮기기. **자막** 단추로 넣은 자막은 시각도 옮겨짐 |

마우스 바퀴는 이렇게 씁니다.

| 바퀴 | 결과 |
|---|---|
| 그냥 | 마우스가 있는 칸 (비디오 / 오디오) 을 세로로 넘김 |
| Ctrl (또는 Shift) | 가로로 넘김 |
| Alt | 확대 · 축소 |

| 아이콘 | 동작 |
|---|---|
| 선택 · 칼 | 도구 바꾸기 |
| 자르기 · 지우기 | 재생 위치에서 자르기, 고른 것 지우기 |

| 연결 (고리) | 영상과 그 소리를 같이 고르고 옮김 |
| **자막** | 재생 위치에 2초짜리 새 자막 넣기 |
| 되돌리기 · 다시 하기 | |
| 초기화 (오른쪽 끝) | AI 가 만든 컷으로 되돌리기 |
| 확대 막대 · 전체 보기 | 타임라인 배율 |

### 그룹

1. 클립을 여럿 고르고 우클릭 → **그룹 만들기** 에서 이름을 붙입니다.
2. 그룹에 든 클립은 인스펙터에서 바꾼 값이 같은 종류 (원본 / 그림 / 소리) 의 클립에 함께 들어갑니다.
3. 인스펙터 머리에 `그룹 이름 · N개` 가 보입니다.

### 인스펙터

비디오 / 오디오 탭으로 나뉩니다. 슬라이더를 두 번 누르면 기본값으로 돌아갑니다.

**변형 (이동 · 확대 · 회전)**

- 원본 클립에 걸면 AI 가 잡은 화면 위에 더해집니다. 원본에서 다시 잘라 내므로 화질은 그대로이고, 원본 바깥은 검게 나옵니다.
- X · Y 숫자는 보기용입니다. 슬라이더나 뷰어 상자로 바꿉니다.
- 뷰어 상자 (재생 위치가 고른 클립 안에 있을 때 뜹니다):
  - 가운데를 끌면 옮겨집니다.
  - 모서리를 끌면 비율을 지키며 크기가 바뀝니다 (맞은편 모서리 고정, Alt 를 누르면 가운데 고정).
  - 붙기 (N) 가 켜져 있으면 화면 · 창의 가장자리와 가운데에 붙습니다.

**색** (탭 셋)

| 탭 | 내용 |
|---|---|
| 밝기 · 대비 · 채도 | 기본 보정 |
| RGBW | 리프트 (어두운 곳) · 감마 (중간) · 게인 (밝은 곳) 마다 R · G · B · W |
| 커브 | 전체 · R · G · B |

- 커브는 눌러서 점을 만들고, 끌어서 옮기고, 점을 두 번 눌러 뺍니다.
- **초기화**는 지금 탭 (커브는 지금 고른 선) 만 처음대로 되돌립니다.
- 미리보기와 렌더는 같은 계산을 씁니다.

**키프레임 (덧 영상 · 그림)**

1. **키 추가**를 누르면 지금 재생 위치의 위치와 크기가 키가 됩니다.
2. 그 뒤로는 위치 · 크기를 바꿀 때마다 (뷰어에서 끌어도) 그 시점에 키가 생깁니다.

| 단추 | 동작 |
|---|---|
| ◀ ▶ | 앞 · 뒤 키로 가기 |
| 부드럽게 | 키 사이를 천천히 출발해 천천히 멈춤 (끄면 일정한 빠르기) |
| 움직임 지우기 | 키를 모두 지우고 지금 자리에 고정 |

**전환 (앞 클립에서)**

- 원본 클립: 바로 앞 클립에서 넘어오는 전환입니다.
- 덧 클립: 같은 트랙에서 끝이 이 클립 시작에 딱 맞닿은 클립이 있을 때만 걸립니다.
- 디졸브 · 닦기 · 밀기 · 원형은 컷 가운데에 걸리며, 두 파일에서 클립 바깥 부분을 빌려 씁니다. 빌릴 부분이 모자라면 짧아지고, 실제 길이가 인스펙터에 나옵니다.
- 검은 화면 · 흰 화면은 컷 바깥을 빌리지 않습니다.

**페이드 · 소리**

- 덧 클립의 페이드는 화면과 소리를 따로 정합니다.
- 소리 크기는 dB 로 정합니다. 브라우저는 원래 크기보다 키울 수 없어서, + dB 는 미리보기에서 원래 크기로 들립니다 (완성본에는 들어갑니다).

**자막**

- 글 · 화자 · 디자인 · 시작 · 끝 · 변형을 고칩니다.
- **원본 시작 · 끝**을 고치면 컷도 함께 바뀝니다 (앞당기면 그만큼 되살리고, 늦추면 그만큼 뺍니다).
- **컷에서 빼기** (Delete): 그 줄의 원본 구간을 컷에서 뺍니다.
- **자막** 단추로 넣은 자막은 완성본 시각에 놓입니다. 끌어서 옮기고 Delete 로 지웁니다.

### 소스 / 이펙트 (왼쪽 칸)

**소스**

- 이 편의 원본, **가져온 파일**, 추가한 폴더가 보입니다. 파일을 타임라인에 끌어 놓으면 클립이 됩니다.
- 탐색기에서 바로 끌어 온 파일:
  - 타임라인에 놓으면 `projects/<id>/media/` 로 복사한 뒤, 놓은 자리부터 차례로 클립이 됩니다.
  - 소스 칸에 놓으면 **가져온 파일**에만 넣습니다.
  - 이름과 크기가 같은 파일은 다시 복사하지 않습니다.
- **폴더 추가**를 누르면 폴더를 고르는 창이 뜹니다. 목록에서 폴더를 빼도 실제 파일은 그대로입니다.

**이펙트**

클립 위에 끌어 놓거나, 클립을 고른 뒤 타일을 누릅니다.

- 골라 둔 클립 위에 놓으면 고른 클립 전부에 걸립니다. 그룹은 늘 함께 걸립니다.
- 화면 효과는 원본 클립 (V1) 에만 걸립니다.

| 갈래 | 들어 있는 것 |
|---|---|
| 화면 효과 | 확대 · 크게 확대 · 다가가기 · 빠르게 다가가기 · 물러나기 · 흔들기 · 세게 흔들기 · 흐리게 · 흑백 · 번쩍 (클립 시작) · 비네트 · 좌우 반전 |
| 색 | 흑백 · 강한 흑백 · 따뜻하게 · 차갑게 · 선명하게 · 바랜 색 · 청록 · 주황 · 세피아 · 시네마 · 노을 · 밤 · 파스텔 · 빈티지 · 밝게 · 어둡게 (클립 색을 통째로 바꿈) |
| 전환 | 디졸브 · 검은 화면 · 흰 화면 · 닦기 ← → ↑ ↓ · 밀기 ← → ↑ ↓ · 원형 (0.5초) |

- 화면 효과의 세기와 길이는 인스펙터의 **효과**에서 바꾸거나 뺍니다.
- 소리 효과는 없습니다. 요청이 있기 전에는 소리에 필터를 걸지 않습니다.

### 전사 자막 탭

| 동작 | 결과 |
|---|---|
| 낱말 누르기 | 그 낱말을 컷에서 빼거나 되살림 |
| Shift + 누르기 | 여러 낱말을 한 번에 |
| 두 번 누르기 | 그 자리로 이동 |

- 뺄 때는 앞뒤 쉼의 가운데까지 잘라 냅니다.
- 되살릴 때는 앞에 0.10초, 뒤에 0.15초 여유를 둡니다.

### 렌더 탭

| 묶음 | 설정 |
|---|---|
| 파일 | 작업 폴더 · 내보낼 곳 · 기준 언어 |
| 영상 | 코덱 (H.264 / H.265), 인코더 (자동 / 소프트웨어), 화질, 해상도, 프레임 |
| 소리 | 비트레이트, 목표 크기 (LUFS) |

- **인코더**: 자동은 그래픽 카드를 먼저 써서 빠르고, 소프트웨어는 느리지만 화질이 가장 좋습니다.
- **화질**: 12–32, 기본 20. 숫자가 작을수록 화질이 좋고 파일이 커집니다.
- **해상도**: 영상 방향에 맞는 크기만 나옵니다 (세로 영상이면 세로 크기만). 원본보다 크게 고르면 늘리기만 할 뿐 선명해지지는 않습니다.
- **목표 크기**: 소리 전체를 한 번에 같은 만큼 키우거나 줄여 맞춥니다. 리미터를 쓰지 않으므로, 가장 큰 소리가 -1.5 dB 에 닿으면 거기서 멈춥니다.
- 설정이 모두 기본이면 구운 조각을 그대로 이어 붙입니다. 하나라도 바꾸면 마지막에 한 번 더 인코딩합니다 (몇 초 더 걸리고, 화질이 한 번 더 압축됩니다).
- 파일 형식은 mp4 만 됩니다.
- **렌더** 단추는 맨 아래에 있습니다. 누르면 단계 · 진행 막대 · 걸린 시간 / 남은 시간 · 마지막 기록이 나오고, 끝나면 프로젝트를 다시 읽습니다.

## 3. 알아 둘 것

- **미리보기와 완성본**: 화면 효과 · 색 · 전환은 같은 계산을 씁니다. 다만 미리보기는 컷 이음에서 그림이 살짝 끊길 수 있고, + dB 소리는 원래 크기로 들립니다.
- **자막 순서**: 자막을 어느 비디오 트랙에 놓아도 완성본에서는 덧 영상 · 그림 위에 그려집니다. 트랙은 자막을 놓는 자리일 뿐입니다.
- **트랙 옮기기**에는 원본 파일 경로가 필요합니다. 옛 프로젝트는 렌더나 AI 편집을 한 번 거치면 됩니다.
- **AI 가 컷을 다시 바꾸면** 덧 클립과 새로 넣은 자막은 그 변화를 따라가지 않아 자리가 어긋날 수 있습니다. 사용자 편집 탭에서의 리플은 함께 움직입니다.
